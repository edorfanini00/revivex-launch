All machine images on this branch derive from the single editable touchscreen only scene at `/Users/edorfanini/Projects/revivex-appliance-launch/private-previews/linc-screen-blender/astra-reconstruction/touchscreen-only/revivex-touchscreen-only-editable.blend`. New serial Blender 5.2.1 CPU Cycles renders were made from fresh temporary scene copies using `/Users/edorfanini/.hermes/workspace/revivex-linc-rebuild/render_linc_hi.py`; they were never generated by an image model. `studio-portrait.webp` is the original three quarter camera. `studio-front.webp` is a front camera variant of that same scene. `screen-detail.webp` is the native integrated display camera. Each is converted from its own PNG render, with no UI drawn in post.

`app-labs.webp` is converted from the real native development screenshot `/Users/edorfanini/Projects/ReviveXNative/design/v36/screenshots/labs-recorded.png`; `app-sleep.webp` is from `/Users/edorfanini/Projects/ReviveXNative/design/v36/screenshots/sleep-recorded.png`. Both contain sample records from a development build. They are not a control interface for the proposed machine. The wordmark uses the existing `public/assets/brand/logo-dark.png`; integration logos are not pictured.

The scene is a visual prototype, not a manufactured device. The inherited glass material and flat studio environment are less convincing than the approved `graphite-original/preview.png`; this branch does not claim photographic evidence or production readiness. No old machine images or v11 frame sequence are referenced by the rebuilt home page.
